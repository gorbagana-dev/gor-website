# Gorbagana Brand Guidelines

This directory contains the official Gorbagana brand guidelines website. It provides comprehensive information about the Gorbagana brand, including logos, colors, typography, and usage guidelines.

## Directory Structure

```
brand-guidelines/
├── index.html              # Main brand guidelines page
├── css/
│   └── style.css          # Stylesheet for the brand guidelines
├── js/
│   └── script.js          # JavaScript functionality
├── fonts/
│   └── Pusia Bold.otf     # Official Pusia Bold typeface
├── images/
│   └── gorbagana-logo.png # Logo assets
└── README.md              # This file
```

## Accessing the Brand Guidelines

The brand guidelines can be accessed at:
- **Local**: `/brand-guidelines/index.html`
- **Production**: `https://gorbagana.io/brand-guidelines/`

## Typography

### Primary Font: Pusia Bold
- **Weight**: 700 (Bold), 800 (ExtraBold)
- **Style**: ALL CAPS
- **Tracking**: -0.02em
- **Use**: Headlines, brand marks, primary messaging

### Secondary Font: Inter
- **Weight**: 400 (Regular), 500 (Medium), 700 (Bold)
- **Use**: Body text, UI elements, secondary content

## Logo Guidelines

### Do's
✓ Use the official logo files  
✓ Maintain proper aspect ratio  
✓ Use sufficient clearspace  
✓ Use high-resolution versions  
✓ Ensure adequate contrast  

### Don'ts
✗ Don't add shadows or gradients  
✗ Don't add outlines  
✗ Don't stretch the logo  
✗ Don't use in low resolution  
✗ Don't place imagery inside the logo  
✗ Don't use low contrast backgrounds
